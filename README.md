# Password Generator

A fast, easy-to-use web application that generates strong, random passwords in real time with customizable character rules to help keep your accounts secure.

🔗 **Live Demo:** [passwordking.netlify.app](https://passwordking.netlify.app/)

---

## ✨ Features

- **Instant Password Generation:** Generate randomized passwords with a single click using the **Generate** button.
- **Customizable Character Options:** Tailor your password complexity by toggling options to include:
  - Uppercase letters (`A–Z`)
  - Numbers (`0–9`)
  - Special characters (`!@#$%^&*`, etc.)
- **One-Click Copy:** Easily copy your generated password to the clipboard for immediate use.
- **Clean & Responsive UI:** Simple, distraction-free interface that works smoothly across desktop and mobile devices.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Deployment:** Netlify
